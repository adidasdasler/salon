# ADR-0002: Docker-изоляция; хостовой Nginx как фасад

**Статус:** принят

## Контекст
На VPS уже живут другие проекты и боты на 80/443. Salon не должен им конфликтовать.

## Решение
Весь стек Salon — внутри docker-сети `salon-net`. Наружу публикуется единственный адрес `127.0.0.1:8080` (внутренний nginx контейнер: SPA по Host + proxy `/v1`, `/socket.io` → backend:4000). Хостовой Nginx (`deploy/host-nginx/salon.conf`) терминирует TLS (certbot wildcard) и проксирует домены Salon на 8080. Порты Postgres/Redis не публикуются вообще.

## Последствия
+ Ноль конфликтов с чужими сайтами; откат = выключить compose
+ Бэкапы pg_dump выполняются exec-ом в контейнер
− Два слоя nginx (настраивать заголовки нужно согласованно)
